# M4 — Worker, notifications, Telegram (closed beta gate)

**Goal:** the app reaches people at the right moment without becoming noise. After this milestone ships, the closed beta starts.

## Must
1. **Worker** (`discipline-back/cmd/worker`, Go + Asynq on Redis, deployed as its own Railway service from the same repo)
   - Per-user jobs scheduled in the user's timezone; next fire time computed DST-safe.
   - Idempotent handlers, retries with backoff, dead-letter queue visible in admin.
   - Moves daily vocabulary word creation here (local 05:00); remove creation from `GET /vocabulary/today`.
   - Moves large exports (from M1) to a background job with an emailed download link that expires.
2. **Notification service**
   - Channels: Telegram, web push (VAPID), email.
   - Types: morning check-in, block start (5 min before), block end check-in, session end, evening shutdown, wind-down (60 min before bedtime), daily word review, weekly review (Sunday evening).
   - Per type and per channel opt-in; quiet hours default from the sleep window; rest days silence task reminders; cap of N notifications per day; every send logged (sent, failed, opened).
   - Copy follows the no-shame principle; every message has a one-tap action or none.
3. **Telegram bot**
   - Webhook verified with the secret-token header; unknown chats ignored.
   - Account linking through a one-time deep-link token (`/start <token>`), unlink from Settings and with `/stop`.
   - Inline buttons: block done / partial / skip, morning check-in quick replies, snooze.
   - Messages in the user's language; respects Telegram rate limits.
   - Telegram Login on the web as an optional sign-in method (hash verified server-side).
4. **Web push:** service-worker handler, subscription per device, cleanup of expired subscriptions.
5. **Email:** weekly summary (opt-in, requires verified email).
6. **Beta tools:** invite codes when `BETA_INVITE_ONLY=true`; in-app feedback form (text) stored and listed in admin.

## Acceptance criteria
- A block at 09:00 Asia/Tashkent triggers its reminder at 08:55 local, also across a DST change for a user in a DST timezone (test).
- Tapping "done" in Telegram updates the block once, even if Telegram retries the webhook (test).
- No notification is sent inside quiet hours or on a rest day for task types (test).
- Worker restart loses no scheduled job (test with Redis restart).
- Opt-out of any type takes effect immediately.

## Events
`notification_sent`, `notification_opened`, `notification_opt_out`, `telegram_linked`, `push_enabled`, `feedback_sent`.

## After deploy (owner)
Invite 20–30 beta users. Collect at least 2 weeks of data before designing M6.
