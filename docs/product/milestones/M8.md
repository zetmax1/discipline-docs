# M8 — Motivation, mini-games, Telegram Mini App

**Goal:** reward consistency (not hours) and give small, capped breaks that feel earned.

## Must
1. **XP and levels**
   - XP for consistency only: morning check-in, kept plan (≥70% of due blocks done), rest day kept, weekly review, daily review goal, habit kept.
   - Never XP for raw hours. Daily XP cap.
2. **Achievements and weekly challenges:** data-driven definitions editable in admin; shown with encouraging copy.
3. **Focus coins** earned from completed focus sessions.
4. **Mini-games**, never full games: the first one each day unlocks after a completed focus block or session; coins buy more time up to a daily cap (default 15 min total, the user can lower it):
   - Daily chess puzzle from the Lichess puzzle database (check its license on database.lichess.org before import).
   - Word memory match and a typing test using the user's own words.
   - Libraries must have permissive licenses compatible with this project (check every chess UI library's license; avoid GPL components unless the project decides to be GPL).
5. **Telegram Mini App:** the same web build inside Telegram; `initData` validated server-side; Telegram theme colors; deep links into Today and focus sessions.

## Acceptance criteria
- No XP rule rewards hours (test over XP rule table).
- Game cap enforced server-side, per local day.
- Mini App sign-in rejects tampered or expired `initData` (test).

## Events
`xp_earned`, `level_up`, `achievement_unlocked`, `game_unlocked`, `game_played`, `miniapp_opened`.
