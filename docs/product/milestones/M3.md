# M3 — Daily loop

**Goal:** the daily loop takes under 2 minutes of logging per day and produces honest data.

## Must
1. **Morning check-in**
   - Sleep start/end (prefilled from the sleep window), sleep quality 1–5, energy 1–5, optional note.
   - One per local day, editable the same day, skippable; ≤ 10 seconds when defaults are right.
2. **Today screen** (replaces the Dashboard)
   - Check-in card until done → Top-3 → current/next block with a Start button → today's timeline → evening shutdown prompt after the user's chosen time.
   - Empty states teach the loop instead of showing zeros.
3. **Focus sessions**
   - Presets 25/5, 50/10, 90/20, custom 10–180 min; long break after 4 sessions.
   - Server stores the session (start, planned length, end, outcome, distractions, linked block). Clients compute the countdown from the server start time, so refresh, a second tab or another device show the same timer.
   - Offline: actions queue locally with idempotency keys and sync later.
   - Break suggestions (walk, water, stretch, eye rest), localized, rotated.
   - Distraction tap + "parking lot" note that lands in the task inbox.
   - Session end: sound/vibration + title change in the open app (web push arrives in M4).
4. **Block check-in:** one tap done / partial / skipped from Today and Planner; actual times default to planned (or to linked sessions); focus rating prompt, skippable.
5. **Evening shutdown:** review today's unfinished blocks (move to tomorrow / later / drop), write one win, pick tomorrow's Top-3. Marks the day closed.
6. **Metrics update:** completed minutes use actual times when present; `partial` counts actual minutes; sessions add break data for M5. Update `app/metrics.py`, contracts and fixtures.

## Acceptance criteria
- A session started on the phone shows the same remaining time on desktop (±1 s).
- Airplane mode: start a session, tap distractions, finish; after reconnect the server has exactly one session with the right data (test with duplicate submits).
- Morning check-in at 00:30 local time belongs to the new local day; a check-in for the previous night's sleep is attributed correctly (tests).
- Today screen has empty, loading, error and offline states at 390 px and 1440 px.

## Events
`checkin_morning_done`, `session_started`, `session_completed`, `session_abandoned`, `distraction_logged`, `block_checked_in`, `shutdown_done`.

## Out of scope
Push/Telegram reminders (M4), habits and balance warnings (M5).
