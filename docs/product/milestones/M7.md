# M7 — Language learning (optional module)

**Goal:** learn real words at the right level with spaced repetition, in a few minutes a day.

## Owner prerequisite: content licensing
- Every word, definition, example, translation and audio file stores its source and license.
- Only licenses that allow this use; attribution and share-alike obligations handled (e.g. CC BY-SA content shown with attribution and kept separable).
- Popular CEFR lists are often not freely licensed. If no usable list exists, derive levels from frequency bands and label them "estimated level".
- The design step must list candidate sources with their licenses before any import code is written.

## Must
1. **Model:** target language (English or Russian) with the UI language as the base; words with part of speech, level, translations (uz/ru/en), examples, optional audio.
2. **Placement test:** adaptive, ~20 items, result shown as an estimated level the user can change.
3. **Daily new words** (default 5, adjustable) created by the worker in the user's timezone.
4. **Spaced repetition with FSRS** (open-source implementation); every review is logged.
5. **Games that all write to the same review log** (a game that doesn't update the schedule is decoration): flashcards, multiple choice, typing/spelling, listening (licensed audio or TTS), matching pairs, 60-second sprint, fill-in-the-blank from example sentences.
6. **Daily review goal** and a streak that follows M5 rules.
7. **Migration:** existing `vocabulary_words` (saved/learned) move into the new model; the old daily dictionary-API flow is removed.

## Acceptance criteria
- Each game produces correct FSRS updates (tests with fixed review sequences).
- The "compelling" case: the stored sense matches the intended part of speech (regression from F-15).
- Content import refuses items without source and license.

## Events
`placement_completed`, `word_reviewed`, `game_played`, `daily_review_goal_met`.
