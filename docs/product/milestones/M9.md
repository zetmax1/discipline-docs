# M9 — Social, AI coach, admin analytics

**Status:** draft. Re-scope with beta data and feedback before designing.

## Social (opt-in)
- Accountability partner via invite link; the partner sees only what the owner shares (streaks, weekly summary).
- Groups/classes with shared challenges; leaderboards by consistency %, weekly, opt-in; never by hours.
- Report and block users; moderation queue in admin.

## AI coach (opt-in)
- Input: computed stats JSON only. No names, emails or free-text notes unless the user opts in for notes.
- Output labeled as AI, in the user's language; never medical advice.
- Provider configurable; per-user monthly budget; caching; graceful fallback when unavailable.
- Evaluation set of ≥20 fixture weeks reviewed before launch.

## Admin analytics
Retention cohorts, activation funnel, notification opt-outs by type, plan acceptance rate, feature-flag rollout status.

## Events
`partner_linked`, `group_joined`, `coach_summary_viewed`, `coach_feedback`.
